# skillware

Turn AI Engineer conference talks into reusable agent skills.

skillware ingests talk transcripts, extracts concrete practices with citations back to the speaker and timestamp, clusters them across talks, and synthesizes them into Agent Skills (SKILL.md) that coding agents can load.

**MVP:** *The AI Engineer Playbook*, built from the AI Engineer site's Markdown transcripts. Later: point it at any YouTube channel.

Status: early. Spec and architecture land first (docs/SPEC.md, docs/ARCHITECTURE.md).
